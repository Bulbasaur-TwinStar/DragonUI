# 🐉 DragonUI v2.7 – TwinStar Edition (MoP 5.4.8 | Helios / Persés)

**DragonUI** is a modern, lightweight, Dragonflight-style user interface overhaul adapted for **TwinStar WoW — Mists of Pandaria 5.4.8 (Helios & Persés)**, originally ported from 3.3.5a by EncarnacionDev and fixed/optimized by **Bulbasaur**.

## ✨ Key Features
* **Zero Lua Errors & MoP 5.4.8 Core:** Updated `.toc` (`50400`) metadata, rewritten API calls, and elimination of combat taint.
* **Class Resources & Endgame Polish:** Eclipse bars, combo points, Monk/Shaman/Paladin support, Valor upgrade levels on gear icons, and heal absorbs.
* **Customization & Layout (`/dragonui edit`):** Dragonflight art, fixed reputation bars, visual drag-and-drop editor, raid frames, and LFG eye positioning (`/lfgmove`).
* **QoL & Integration:** Fixed guild bank stack splitting, Dark Mode support across 10 client languages, and full compatibility with DBM, WeakAuras, and Details!.

## ⌨️ Slash Commands
* `/dragonui` or `/dui` – Open main configuration
* `/dragonui edit` – Toggle layout editor mode
* `/lfgmove` – Reposition the LFG/RDF minimap eye

## 📥 Installation
1. Download **`DragonUI-TwinStar.zip`** from the [Releases page]( *(https://github.com/Bulbasaur-TwinStar/DragonUI/releases/tag/v2.7)*.
2. Extract and replace `DragonUI` and `DragonUI_Options` in `World of Warcraft\Interface\AddOns\`.
3. **Restart your game client completely.**
